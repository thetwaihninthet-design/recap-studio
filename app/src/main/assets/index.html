လက်ရှိ Ratio, Color filter, စာတန်း style နဲ့ Trim အပိုင်းအတိုင်း MP4 ထုတ်ပေးပါတယ်။ Video ကို အစအဆုံး play ရင်း record လုပ်တာမို့ video အရှည်အတိုင်း အချိန်ကြာပါမယ် — record လုပ်နေချိန် tab ကို မပိတ်ပါနဲ့။

💡 MP4 အကြောင်း: Browser က MP4 recording ကို support လုပ်ရင် MP4 တိုက်ရိုက် ထုတ်ပေးပါတယ်။ Support မလုပ်တဲ့ browser (ဥပမာ Firefox / Chrome အဟောင်း) ဆိုရင် WebM record လုပ်ပြီး ffmpeg.wasm နဲ့ browser ထဲမှာပဲ MP4 ပြောင်းပေးဖို့ ကြိုးစားပါမယ် — ပထမအကြိမ်မှာ ffmpeg (≈ 31MB) ကို CDN ကနေ load လုပ်ရလို့ Internet + အချိန် နည်းနည်း ပိုကြာနိုင်ပါတယ်။ ဘယ်လိုမှ မရရင် WebM ဖိုင်ကို အစားထိုး download ပေးပြီး ရှင်းပြပါမယ်။

🎙 TTS — စာကို အသံထွက်ဖတ်ရန်

3 ဘာသာ ရပါတယ် — မြန်မာ (my-MM) • English (en-US) • ไทย (th-TH)။ မြန်မာအတွက် သီဟ (Thiha — အမျိုးသား, my-MM-ThihaNeural) နဲ့ နီလာ (Nilar — အမျိုးသမီး, my-MM-NilarNeural) ဆိုတဲ့ Azure Neural အသံ ၂ မျိုး အောက်မှာ ရွေးနိုင်ပါတယ်။ ဖုန်းမှာ မြန်မာအသံ မရှိရင် ☁ Cloud အသံ ကို သုံးပါ — script စာသားကို Google TTS ဆီ ပို့ပြီး မြန်မာအသံ ပြန်ဖတ်ပေးပါတယ် (Internet လိုပါတယ်)။ Device အသံ ရှိတဲ့ ဘာသာဆိုရင် device အသံနဲ့လည်း ဖတ်နိုင်ပါတယ်။

⚡ အလိုအလျောက် Script + အသံ (ခလုတ်တစ်ချက်)

ကိုယ်တိုင် script ရေးစရာ မလိုပါ။ အောက်က Movie Title နဲ့ Genre ကို ဖြည့်ပြီး ဒီခလုတ်ကို နှိပ်လိုက်ရင် — video တင်ထားရင် ၎င်းရဲ့ duration အလိုက် အချိန်ခွဲပြီး — script အပြည့်အစုံ ရေးပေး → စာတန်း အလိုအလျောက် ဖန်တီးပေး → ရွေးထားတဲ့ အသံနဲ့ တန်းဖတ်ပေးပါမယ်။

🤖 AI Recap — Video ကိုယ်တိုင်ကြည့်ပြီး ရေးတာ

ဒီ tool က browser ထဲမှာပဲ အလုပ်လုပ်တဲ့ static tool ဖြစ်လို့ video ကို server AI ဆီ ပို့ပြီး ကြည့်ခိုင်း၊ နားထောင်ခိုင်းတာမျိုး ဒီ version မှာ မလုပ်နိုင်သေးပါ — အဲဒါအတွက် server ပါတဲ့ version လိုပါတယ်။ လောလောဆယ် လုပ်လို့ရတာက — ဇာတ်လမ်းအကျဉ်း (သို့) ကိုယ်သိထားတဲ့ အကြောင်းအရာကို အောက်မှာ paste လုပ်လိုက်ရင် ၎င်းကို recap script ပုံစံ ပြန်စီပေးပြီး စာတန်း + အသံ တန်းထုတ်ပေးပါတယ်။

⏱ Video အချိန် (မိနစ် : စက္ကန့်) အတိုင်း ညှိမယ်

Video ရဲ့ အရှည် အတိအကျကို ဖတ်ပြီး Script ရဲ့ ခန့်မှန်း ဖတ်ချိန်နဲ့ တိုက်စစ်ကာ — Speed ကို အလိုအလျောက် ချိန်ပေးပြီး စာတန်း အချိန်တွေကို video အစကနေ အဆုံး ပြန်ခွဲပေးပါတယ်။ ဥပမာ video က ၂ မိနစ် ၃၅ စက္ကန့် ဆိုရင် narration က အဲဒီ ၂:၃၅ အတွင်း ကိုက်အောင် ညှိပေးပါတယ်။ Trim သတ်မှတ်ထားရင် Trim အပိုင်းရဲ့ အရှည်နဲ့ ညှိပါမယ်။

🎙 မြန်မာ အသံ ရွေးရန် — သီဟ / နီလာ (Azure Neural)

ဒီ အသံ ၂ မျိုးက Microsoft Azure ရဲ့ Burmese Neural အသံတွေပါ။ ဘာသာစကားကို မြန်မာ ရွေးထားချိန်မှာ အလုပ်လုပ်ပါတယ်။ တစ်ခုကို နှိပ်ရွေးပါ — ရွေးထားတဲ့ အသံနဲ့ script နဲ့ စာတန်းတွေကို ဖတ်ပေးပါမယ်။

⚠ မူပိုင်ခွင့် သတိပေးချက်: ကိုယ်ပိုင် video (သို့) အသုံးပြုခွင့်ရှိတဲ့ video ကိုပဲ edit / ပြန်တင်ပါ။ YouTube/TikTok က သူများ video ကို download လုပ်ပြီး ပြန်တင်တာက platform စည်းကမ်းနဲ့ မကိုက်ညီနိုင်ပါ။ Video edit အားလုံး browser ထဲမှာပဲ လုပ်ပြီး သင့် video ကို server ပေါ် မတင်ပါ — ဒါပေမဲ့ ☁ Cloud TTS သုံးရင် ဖတ်စေချင်တဲ့ script စာသားကိုတော့ အသံပြောင်းဖို့ Google TTS ဆီ အင်တာနက်ကနေ ပို့ရပါတယ်။ သီဟ (my-MM-ThihaNeural) / နီလာ (my-MM-NilarNeural) အသံ သုံးရင်လည်း script စာသားကို Microsoft Azure Speech ဆီ ပို့ရပါတယ် — video file ကိုတော့ ဘယ်တော့မှ မပို့ပါ။
