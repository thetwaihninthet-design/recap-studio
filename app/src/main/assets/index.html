② AI ဆီ ပို့မယ် Video + Prompt

Video file နဲ့ အောက်က prompt ကို AI (Gemini) ဆီ အတူတူ ပို့မယ် — AI က video ကို ကြည့်ပြီး မြန်မာ recap script ရေးပေးမယ်။
