🎞️ နောက်ဆုံး MP4 Video ထုတ်ရန်

လက်ရှိ Ratio, Color filter, စာတန်း style နဲ့ Trim အပိုင်းအတိုင်း MP4 ထုတ်ပေးပါတယ်။ Video ကို အစအဆုံး play ရင်း record လုပ်တာမို့ video အရှည်အတိုင်း အချိန်ကြာပါမယ် — record လုပ်နေချိန် tab ကို မပိတ်ပါနဲ့။

💡 MP4 အကြောင်း: Browser က MP4 recording ကို support လုပ်ရင် MP4 တိုက်ရိုက် ထုတ်ပေးပါတယ်။ Support မလုပ်တဲ့ browser (ဥပမာ Firefox / Chrome အဟောင်း) ဆိုရင် WebM record လုပ်ပြီး ffmpeg.wasm နဲ့ browser ထဲမှာပဲ MP4 ပြောင်းပေးဖို့ ကြိုးစားပါမယ် — ပထမအကြိမ်မှာ ffmpeg (≈ 31MB) ကို CDN ကနေ load လုပ်ရလို့ Internet + အချိန် နည်းနည်း ပိုကြာနိုင်ပါတယ်။ ဘယ်လိုမှ မရရင် WebM ဖိုင်ကို အစားထိုး download ပေးပြီး ရှင်းပြပါမယ်။

⚡ အလိုအလျောက် Script + အသံ (ခလုတ်တစ်ချက်)

Title + Genre ဖြည့်ပြီး နှိပ်ပါ — video အရှည်အတိုင်း အပိုင်း (5/10/30 မိနစ်) ခွဲပြီး script → စာတန်း → အသံ အလိုအလျောက် လုပ်ပေးပါတယ်။ ⚠ Template script က ဇာတ်လမ်း အကြောင်းအရာ အစစ် မသိပါ — အပိုင်းတိုင်း အသံထွက်ဖို့ scaffold ပဲ။ အကြောင်းအရာ အမှန်က အောက်က 🤖 AI Recap (Frame ပို့ → AI ရေး → paste) ကနေ ထည့်ပါ။

တစ်ကားလုံး အပိုင်းခွဲ — တစ်ပိုင်း ဘယ်နှစ်မိနစ်

🤖 AI က တစ်ကားလုံး ကြည့်ပြီး ရေးမယ် — App ထဲကပဲ

Video ကို Server AI (Gemini) ကို ပို့မယ် — AI က video ကို ကြည့်ပြီး + နားထောင်ပြီး တစ်ကားလုံး ရေးပေးမယ်။ စကားမပြောတဲ့နေရာမှာ ဇာတ်လမ်းလို ပြောမယ်၊ ဒိုင်ယာလော့ရှိတဲ့နေရာမှာ ဇာတ်လမ်းထဲက စကားအတိုင်း ပြောမယ်။ အချိန် [မိနစ်:စက္ကန့်] နဲ့ ကိုက်မယ်။

Server AI အခြေအနေ စစ်နေပါတယ်…

မစရသေးပါ — video တင်ပြီး ဒီခလုတ်ကို နှိပ်ပါ။ Video တင်တာ + AI ရေးတာ မိနစ်အနည်းငယ် ကြာနိုင်ပါတယ်။

🤖 AI Recap — တကားလုံး Gemini / GPT / Muse နဲ့ ရေးမယ်

အဆင့် ၁ — Frame ပုံ ထုတ်မယ် (အပိုင်းတိုင်း 4 frame, အချိန် + အပိုင်းနံပါတ် ပါမယ်) → အဆင့် ၂ — Prompt ကူးပြီး Gemini / GPT / Muse ကို ပုံနဲ့အတူ ပို့မယ် → အဆင့် ၃ — AI ရေးတဲ့စာကို အောက်မှာ paste လုပ်ပြီး အသံထုတ်မယ်။ AI က မိနစ်:စက္ကန့် အချိန်နဲ့ ရေးပေးရင် စာတန်း + အသံက video နဲ့ အချိန်ကိုက် ဖြစ်မယ်။ အပိုင်းလိုက် paste လုပ်ချင်ရင် ➕ ပေါင်းထည့်မယ် ကို ဖွင့်ထားပါ။

➕ အပိုင်းလိုက် ပေါင်းထည့်မယ်
AI စာကို အပိုင်းလိုက် paste လုပ်ရင် အဟောင်းကို မဖျက်ဘဲ ပေါင်းထည့်မယ် — Part 1, Part 2... အကုန် စုမယ်

အချိန်မပါတဲ့ စာဆိုရင် အသံ ဖတ်ချိန်အတိုင်း အစအဆုံး စီပေးပါမယ်။ [မိနစ်:စက္ကန့်] ပါရင် အဲဒီအချိန်အတိုင်း စာတန်း ပေါ်မယ်။ 📄 .txt ခလုတ်က စာတန်း လိုင်းတွေ အကုန်လုံးကို [မိနစ်:စက္ကန့်] နဲ့ .txt file အဖြစ် ထုတ်ပေးပါမယ်။

⚠ မူပိုင်ခွင့် သတိပေးချက်: ကိုယ်ပိုင် video (သို့) အသုံးပြုခွင့်ရှိတဲ့ video ကိုပဲ edit / ပြန်တင်ပါ။ YouTube/TikTok က သူများ video ကို download လုပ်ပြီး ပြန်တင်တာက platform စည်းကမ်းနဲ့ မကိုက်ညီနိုင်ပါ။ Video edit အားလုံး browser ထဲမှာပဲ လုပ်ပြီး သင့် video ကို server ပေါ် မတင်ပါ — ဒါပေမဲ့ ☁ Cloud TTS သုံးရင် ဖတ်စေချင်တဲ့ script စာသားကိုတော့ အသံပြောင်းဖို့ Google TTS ဆီ အင်တာနက်ကနေ ပို့ရပါတယ်။ သီဟ (my-MM-ThihaNeural) / နီလာ (my-MM-NilarNeural) အသံ သုံးရင်လည်း script စာသားကို Microsoft Azure Speech ဆီ ပို့ရပါတယ် — video file ကိုတော့ ဘယ်တော့မှ မပို့ပါ။
